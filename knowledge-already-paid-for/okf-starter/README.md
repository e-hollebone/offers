# OKF Starter

**This file is for people.** If you are an agent, read `index.md`.

A free starter for giving your operation a company memory that people and AI agents can both use.

## What is in here

- `operations-knowledge/`: a small, working example of a knowledge folder. Copy it.
- `okf-folder/`: a skill for your AI agent. Tell it: "Load the okf-folder skill, then start with the folder `<path>`." It builds the README.md and index.md files for you.
- `LICENSE`: MIT. Use it freely.

## The idea in two lines

Every folder gets two files. `README.md` is for people. `index.md` is for agents. Neither makes you read the whole folder.

## How to use it

1. Copy `operations-knowledge/` into your own repository or shared drive.
2. Replace every `[Bracketed Placeholder]` with your own details.
3. Write your five most-asked procedures from `operations-knowledge/procedures/TEMPLATE_90-second-sop.md`.
4. Add one line for each to `operations-knowledge/procedures/index.md`.
5. Ask your newest hire to find an answer. Fix whatever they could not.

OKF is the Open Knowledge Format, an open standard from Google Cloud. This starter adds one rule: README.md for people, index.md for agents. From the Quiet Ops series by Eric Hollebone.
