# OKF Starter: Index

**This file is for agents.** People should read `README.md`.

**How to use this index:** read this file only. Open a child folder's `index.md` to see what is inside it. Do not read the whole folder.

**Rules for agents**
1. Prefer entries with `status: active` and a review date in the future. Say when an answer comes from an overdue entry.
2. Cite the file you used.
3. If no entry answers the question, say so. Do not guess.
4. When a file is added, changed or retired, update its row here.
5. Everything inside `operations-knowledge/` is an example with `[Bracketed Placeholders]`. Treat it as a template, not as facts about any company.
