# Procedures

**This file is for people.** If you are an agent, read `index.md` instead.

## Why this folder exists

One place for how [Company Name] does its recurring work. Each procedure is one page and passes the 90-second test: a capable new hire can find it, read it and act on it in 90 seconds.

## The 90-second format

Every procedure answers five things, in this order:

1. **Question:** the question someone is actually asking
2. **Answer:** the plain answer
3. **Next step:** the one thing to do now
4. **Owner:** the person who keeps it right
5. **Review date:** when it is next checked

If it does not fit on one page, split it into two procedures.

## How to add a procedure

Copy `TEMPLATE_90-second-sop.md`, fill it in, and add one line to `index.md`.
