# okf-folder

The skill. `SKILL.md` holds the instructions your agent follows.

**Owner:** Eric Hollebone. **Last reviewed:** 2026-10-06.

To use it, tell your agent: "Load the okf-folder skill, then start with the folder `<path>`."

The skill works in four steps: look and ask, write README.md and index.md for each folder, add frontmatter to documents, and report what is missing. It never overwrites your files without a yes.

You do not need to read `SKILL.md` to use it.
